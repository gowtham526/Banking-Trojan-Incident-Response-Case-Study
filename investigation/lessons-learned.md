# Lessons Learned

This project helped me understand how malware infections can be investigated using network traffic analysis.

## Technical Skills Gained

- Learned how to analyze PCAP files using Wireshark.
- Understood the difference between HTTP GET and HTTP POST requests.
- Learned how HTTP 302 redirects can be used during malware delivery.
- Learned how to reconstruct an attack timeline.
- Learned how to identify Indicators of Compromise (IOCs).
- Learned how to validate malware artifacts using VirusTotal.
- Learned how to correlate network traffic with threat intelligence.

---

## Investigation Experience

Through this investigation I was able to:

- Identify the infected host.
- Trace the malware delivery chain.
- Identify downloaded malware files.
- Observe command-and-control communication.
- Document findings in a structured incident report.
